# Installation

## Browser app

Run `python3 -m http.server 8080` from the repository root and open `http://localhost:8080`.

## Python desktop environment

Run `scripts/setup.sh` on Linux/macOS or `scripts/setup.bat` on Windows. Pandoc and Tesseract are optional system tools for enhanced document and OCR workflows.

## Flutter

Install the stable Flutter SDK, then run `cd mobile/converter_mobile && flutter pub get`.
