# Troubleshooting

- If a conversion reports an existing output, choose a new destination; the application never overwrites silently.
- If PDF-to-DOCX is unavailable, install the pinned Python dependencies and ensure the source PDF is not password protected.
- If Flutter commands are unavailable, install the stable Flutter SDK and rerun `flutter doctor`.
- If an image cannot be read, verify its actual contents rather than only changing its extension.
