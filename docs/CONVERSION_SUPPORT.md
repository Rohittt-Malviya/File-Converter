# Conversion support

Fully local Python support includes common image formats (PNG, JPEG, WebP, BMP, TIFF), text/Markdown conversion, CSV/XLSX conversion, PDF rendering/merging/splitting/text extraction, and DOCX text extraction. PDF-to-DOCX uses `pdf2docx`; Markdown quality improves when Pandoc is installed. Encrypted PDFs are detected and rejected unless unlocked.
